# Blade Toss

Free single-file HTML5 knife throwing game. Time your throws, fill the
spinning log with knives, pop apples for bonus points, and survive the
tricky boss log every 5th level. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/blade-toss/

- Tap / click / Space to throw, procedural WebAudio sounds
- Procedural wood & steel visuals, no dependencies
